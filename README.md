# Apnea Dry Training

A minimal local-first web app for apnea dry training.

## Features

- **CO₂**, **O₂**, **Wonka**, and **Custom** training tables
- Guided session runner with countdown timer and voice announcements
- Session history stored in browser localStorage

## Usage

Open `index.html` directly in a browser, or serve locally:

```bash
python3 -m http.server
```

No build step. No dependencies.

## Table types

| Type | Description |
|------|-------------|
| CO₂  | Fixed hold, decreasing breathe — builds CO₂ tolerance |
| O₂   | Increasing hold, fixed breathe — builds O₂ efficiency |
| Wonka | Hold until first contraction, then countdown — variation of CO₂ |
| Custom | Set hold and breathe per round manually |

## Tips

- Tap a table to start a session. Long-press to edit.
- During a Wonka session, tap **First Contraction** when you feel the first diaphragm spasm.
- Voice announcements use the Audio API — allow audio in your browser.

## Regenerating voice clips

The voice clips under `audio/female/` and `audio/male/` are pre-generated and committed. To regenerate them — for example after editing the wording in `scripts/gen_audio.py` — run:

```bash
uv run scripts/gen_audio.py
```

The script supports two TTS backends, selected via `AUDIO_PROVIDER`:

| Provider | Default | Notes |
|---|---|---|
| `local` (default) | on-device [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) via `mlx-audio` | macOS / Apple Silicon. No API key, no quotas. Voice quality is acceptable but mechanical. |
| `elevenlabs` | ElevenLabs cloud TTS | Higher quality. Requires `ELEVEN_LABS_API_KEY` in `.env` and burns API credits. |

The script skips any clip whose `.opus` *and* `.mp3` files already exist, so re-runs are free; delete the target files to force a regen.

### ElevenLabs options

```bash
AUDIO_PROVIDER=elevenlabs uv run scripts/gen_audio.py
```

Environment variables:

| Var | Default | Description |
|---|---|---|
| `ELEVEN_LABS_API_KEY` | – | Required. Loaded from `.env` automatically. The key needs the `voices_read` and `text_to_speech` permissions. |
| `ELEVENLABS_VOICE_FEMALE` | `Lily` | Voice name (searched in your library) or 20-char voice ID. |
| `ELEVENLABS_VOICE_MALE` | `George` | Same. |
| `ELEVENLABS_MODEL` | `eleven_multilingual_v2` | Any model ID supported by your tier. |
| `ELEVENLABS_OUTPUT_FORMAT` | `mp3_44100_128` | See ElevenLabs docs for tier-allowed formats. |
| `ELEVENLABS_SPEED` | `0.9` | `VoiceSettings.speed`, valid range `0.7`–`1.2`. |

**Free-tier note**: only ElevenLabs *premade* voices work via API on free plans — *library* and *professional* voices return `402 paid_plan_required`. The current defaults (Lily / George) are premade and free-tier safe. Run the bundled list query to inspect what your account exposes.

A full regen of every clip in both voices costs roughly **400 credits** on `eleven_multilingual_v2` (≈4% of the 10k-credit free monthly allowance).
